## 5. Exact install / deploy / rollback commands

```bash
# Build artifact (workstation or CI)
./deploy/build-release.sh <git-sha>

# Clean-room install (staging VM, from artifact)
sudo PDU_STAGING=1 bash deploy/install.sh /path/pdu-manager-<sha>.tar.gz

# Transactional deploy (staging or prod VM; auto-rollback on health failure)
sudo bash deploy/deploy-release.sh /path/pdu-manager-<sha>.tar.gz

# Health checks (read-only; app|https|full modes)
bash deploy/healthcheck.sh http://127.0.0.1:5000 full

# Rollback to prior known-good release
sudo bash deploy/rollback.sh            # or explicit: sudo bash deploy/rollback.sh <sha>
```
